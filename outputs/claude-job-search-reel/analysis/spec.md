## Polish

- Tiny wide UI → narrow capture and one relevant control at a time, minimum 32px UI text in final.
- No provenance in animated listings → real source URLs/dates, or clearly marked illustrative sample.
- Invented match scores → evidence and gaps.
- Brand-like orange robot and student likeness → Hammad and an original abstract assistant panel.
- Unclear third-party UI montage → original recording of actual supported client; no fabricated connected status.
- Long almost-static form section → sequential highlights tied to voice, keeping steps intact.
- Claim-heavy comedy → original practical hook; source claims corrected.
- Low visual hierarchy in opening architecture → closer presenter crop and legible five-step rail.
- Blank/black transition around 66s → short continuous color fade, no black gap.

Recording dependencies: `shots/recording-manifest.json`. Never render a pending output as though it was recorded.
