# Facts checked · 20 October 2026

Microsoft official repository verified through GitHub API: `microsoft/playwright-mcp`, 38,399 stars at check time, Apache-2.0. Stars are volatile and omitted from public copy.

- Job guarantee is unsupported. Replace with preparation assistance.
- Free applies to the open-source browser package; do not call Claude or the entire workflow free.
- One paste omits runtime/client setup and permissions.
- A recent listing does not guarantee a stronger application or less competition.
- Exactly ten matches and displayed match percentages are illustrative; request up to ten with evidence.
- Every form is not supported universally; site access and compatibility vary.
- LinkedIn bot prohibition does not establish a lunchtime-ban prediction.
- Ten applications a day is not a verified safe quota for company sites.
- Stopping before Submit does not prevent data transmission from earlier form entry/upload.
- Generic company boards and the animated sheet are not evidence of actual results.

- Official Microsoft Playwright MCP supports accessibility snapshots, navigation, form filling and uploads; Node.js 18+ and an MCP client are requirements; Apache-2.0 licence. [https://github.com/microsoft/playwright-mcp](https://github.com/microsoft/playwright-mcp)
- Claude Desktop supports local MCP servers; setup depends on client configuration and organizational controls. [https://support.claude.com/en/articles/10949351-getting-started-with-local-mcp-servers-on-claude-desktop](https://support.claude.com/en/articles/10949351-getting-started-with-local-mcp-servers-on-claude-desktop)
- Desktop manual configuration uses Developer/Edit Config and requires a full restart. [https://modelcontextprotocol.io/docs/develop/connect-local-servers](https://modelcontextprotocol.io/docs/develop/connect-local-servers)
- Claude access, plans and usage limits are separate from the Playwright open-source package. [https://claude.com/pricing](https://claude.com/pricing)
- LinkedIn User Agreement prohibits unauthorized bots and scraping; no timing for a ban or universal safe daily quota is stated. [https://www.linkedin.com/legal/user-agreement](https://www.linkedin.com/legal/user-agreement)

The proposed workflow/prompt is a design, not a claim that it has already been executed. Human review of eligibility is required; no application was sent and no real personal data was entered.
