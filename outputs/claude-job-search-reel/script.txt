Still opening twenty career tabs and rewriting the same application? Here is a five-step workflow to prepare your shortlist with Claude, while you keep control of every submission. First, connect Microsoft’s Playwright browser tool to Claude. The tool is open source; Claude access and usage are separate. Second, add your resume and specify the role, location and date range. Third, search company career pages for recent openings, and keep the source links. If a posting date is missing, flag it. Fourth, compare each role with your actual experience, then put up to ten strong matches in a sheet, with evidence and gaps. Fifth, draft the application fields and a company-specific answer using only facts you can support. Where a site permits automation, it can help fill the form, but it will not work everywhere. Stop before Submit. Check the resume, dates, eligibility and every answer yourself. Comment JOBKIT for the setup, prompt and review checklist!
