## Accessibility

1. Cover: an AI portrait of Hammad in a dark casual shirt fills the slide, with a navy fade behind the title, “Build your path into AI engineering.” A light-blue label says “Free learning resources.” The subtitle introduces six stages and a working project at every step.

2. Route overview on an off-white background. Six numbered stages are listed: foundations; train, test and compare; the training loop; evidence-grounded LLMs; agents with boundaries; and dependable deployment. A note says progress depends on starting point and practice time and does not guarantee hiring.

3. Stage 1, “Learn the foundations.” A blue diagram reads Python to Data to Tests. Learn functions, files, testing and a small API request, plus SQL, Git and vector math. Suggested proof: a CSV-cleaning script you can explain. Resource label: CS50P, Python and SQL documentation.

4. Stage 2, “Train. Test. Compare.” A diagram shows Data to Train to Evaluate. Start with regression and classification, keep a separate test set, and check precision and recall. Suggested proof: a classifier with a baseline and error analysis. Resource: Google Machine Learning Crash Course.

5. Stage 3, “Learn the training loop.” A diagram shows Input to Network to Output. Follow tensors through a small PyTorch network and inspect loss, gradients and validation results. Suggested proof: an image classifier with explained failures. Resource: PyTorch Learn the Basics.

6. Stage 4, “Ground an LLM in evidence.” The diagram shows Question to Retrieve to Cite. Topics include tokens, context, prompts, structured output, document chunks and source passages. Suggested proof: a document assistant that can say it does not know. Resource: Hugging Face LLM Course.

7. Stage 5, “Give agents boundaries.” A diagram reads Plan to Approve to Act. Define a narrow tool, permissions and allowed actions; test tool errors, state and human approval. Suggested proof: an assistant that drafts an action before executing it. Resource: Hugging Face Agents Course.

8. Stage 6, “Ship something dependable.” A diagram reads API to Deploy to Monitor. Validate requests, handle failures, log errors and track latency, usage and model costs. Suggested proof: a deployed demo with tests and a short runbook. Resources: FastAPI tutorial and Docker Get Started.

9. Portfolio slide, “Show what you can build.” Five projects: a clean-data pipeline, a measured classifier, a small image classifier, a cited document assistant and a tool-using assistant. Then deploy project 4 or 5. Add tests, a README, evaluation results and a short runbook.

10. Closing navy slide, “Build one. Then level up.” The route runs from foundations through machine learning, deep learning, LLMs, agents and deployment. A light-blue panel asks viewers to save the roadmap and choose a first project. The slide mentions a companion guide and notes that hosting, compute, APIs and optional certificates may cost money.
