# Small-change checklist

Review draft; not published.

1. Identify the exact element and intended change.
2. State existing behavior that must remain.
3. Request the smallest relevant change and an explanation for dependencies.
4. Inspect the diff and rendered result.
5. Treat unexpected new features as separate requests.

Prompt: “Change only the specified button label to Start. Preserve current behavior. Explain any necessary change outside that component before implementing it. Show the diff and verify the result.”

This can clarify scope; it does not guarantee model behavior.
