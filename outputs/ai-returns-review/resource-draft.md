# AI return-check prompts

Review draft; not published.

## Find possible returns

Review the receipts I provide. List possible returns with item number, order and delivery dates, deadline, condition requirements, shipping/restocking fees, source policy links, and information you cannot verify. Sort by deadline. Do not submit or send anything.

## Prepare one request

For item [number], check the exact retailer policy and prepare a return-request draft. Show the proposed next action and any fees. Wait for my approval before sending, submitting, cancelling or accepting a charge.

A receipt alone may not establish eligibility. A request is not a refund. Account access, tools and regional availability vary. Use the actual merchant policy, not a generic return window.
