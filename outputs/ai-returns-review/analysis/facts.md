## Claims that need correction

1. **“Whatever AI you’re using”** overstates parity. An assistant needs the relevant email/browsing tools, account access and permissions; some tools only draft an answer.
2. **Find everything ordered / everything still returnable** is not guaranteed. Email can omit purchases and delivery/condition information; a model can miss or misread a rule. Use “possible returns”, links, dates and explicit unknowns.
3. **“Handle it”** is underspecified for sending messages, accepting fees or cancelling anything. The original should ask for a draft and concrete next step first, then review the exact item, terms and action.
4. **Colleague’s glasses returned within minutes, USPS label and nearest post office** is the reference creator’s anecdote. No primary transaction evidence is shown. Do not narrate it as Hammad’s/team’s experience. A request or label also does not establish a refund.
5. **Save hundreds** is an unmeasured possibility, not a demonstrated result. Remove the monetary headline; use “check return deadlines” or “reduce return admin”.
6. **Same thing for software subscriptions** conflates an audit with contract cancellation/refund. A renewal list is a useful analogy; cancellation timing, authority, data export, service access and fees depend on the contract. The final script says audit first and check the contract.
7. **Proactive return-window alerts** can be an agent use case, but neither the source footage nor these general pages prove this specific reminder exists in Hammad’s account. Do not show an unsolicited “return alert” as a real received event unless recorded.
8. ChatGPT/Claude logos appear in the source, but the reel does not demonstrate either product. Avoid implying feature parity through a logo collage.

Usable on-screen rule: **“Check the policy. Review the draft. Approve the exact action.”**
