1. How LLM inference works

Why does an AI answer pause before it starts, then arrive piece by piece?

Prefill and decode do different work. The prompt is tokenized and processed, the model builds reusable key-value state, and each ordinary decoding step selects another token. Scheduling and memory movement matter as much as the visible chat interface.

This explainer follows one example through that path and separates time to first token from output speed. If you build AI applications, measure both before choosing an optimization.

2. The AI agent blueprint

A useful AI agent starts with a clear task and a way to check the result.

This map separates six pieces that are often bundled together: skills, knowledge sources, subagents, the agent loop, MCP connections and plugins. They solve different problems. Installing more of them does not automatically make an agent more reliable.

Start with the smallest working system. Add retrieval when evidence is missing, delegation when a bounded task benefits from it, and integrations when the task requires an external action. Keep permissions and verification explicit.

5. Track website changes with Firecrawl

An agent monitoring a web page should be able to tell you what changed.

Firecrawl’s change tracking compares a tracked scrape with its previous snapshot. You can request a Git-style line diff or a structured field comparison, then decide which changes matter to your workflow.

That is useful for documentation, release notes and other sources that evolve. The first scrape establishes a baseline; a later scrape can return the difference. Scheduling those checks is a separate part of the system.

6. The new-model hype cycle

A new model drops. We declare a new era. Then the next model drops.

The excitement is understandable. But the useful question stays the same: does this model perform better on the work you actually need done?

Keep a small set of real tasks. Compare quality, latency, cost and the failures you can tolerate. Let that evidence decide what goes into your workflow.
