Audit: every page 200, canonical and Open Graph right, all 12 new blog posts in the sitemap, GA4 loading. Search Console is verified but its API key is unset, so the Monday report skips it.

  1. Titles. Blog and About titles run 98–111 characters because the root template appends the full brand string. Use the post's own 60-character title and shorten the template to "| withhammad". API
  2. Internal links. /resources is in no menu and not on the home page; resource pages link to zero blog posts and the blog to zero resources. Add the nav entry, a home strip of newest guides, and resource ↔ blog links both ways. API
  3. Video schema. The 12 posts embed a reel with no VideoObject. Add it with real duration and upload date, plus a video sitemap. Realistic ceiling: video badge in results, not full video rich results, unless a watch page is added. API
  4. Entity cleanup. The site schema still names the old Instagram @with.hammad; add Facebook and TikTok, author links to /about, Article images and dates. API
  5. Speed. /blog HTML is 828 KB (45 inline cover images); home LCP 6.9 s against a 2.5 s budget. Lazy-load covers, static JPGs, defer the 3D bundles. API
  6. FAQ. Google ended FAQ rich results in May 2026; keep the visible Q&A as answer-engine text, stop counting the markup as a win.
  7. Search Console API. Needs a service-account credential from you so the weekly report shows clicks per page. You

Why: Google's AI features guidance asks for crawlability, strong internal linking, page experience and text content, which are exactly the gaps in items 2 and 5. An Ahrefs March 2026 study of 863k results found only 38% of AI-cited URLs ranked top-10, so answer-first pages get cited without ranking.
