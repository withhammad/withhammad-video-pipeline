Audit findings:
1. Every AI Short has `#Shorts` in the title AND again at the end of the description, so "#Shorts" appears twice in the hashtag set. YouTube shows up to 3 hashtags above the title; the duplicate wastes one slot (see E1).
2. The first description line alternates between "Free guide: <url>" and a topic sentence. YouTube uses the first sentence as the search snippet and only ~100 chars show above the fold on the Shorts player (E6, E7); the keyword sentence must come first, link second.
3. Several descriptions carry the line "AI avatar of me." as a disclosure. Fine in video descriptions (rule: disclosure stays there), wrong in the channel description.
4. Channel title has no topic keyword; channel trailer is a 24-minute video; no Shorts-by-topic sections; legacy off-topic playlists are still in the Home layout ("All playlists" section).
5. Tags are search-style and include misspellings (good: YouTube says tags are for misspellings, E9). The 10-27 LinkedIn Short uses the generic 10-tag default set instead of video-specific tags.
6. Long videos have no chapters in their descriptions (first 2 lines show no `00:00`), and only the trailer has an end-screen-style CTA.

## 3. Shorts description template

Rules applied: keyword sentence first (search snippet + ~100 chars above the fold), guide link second, `#Shorts` once, 3 hashtags total so all 3 show above the title (E1, E6, E7), related video set to the matching long video (E4), disclosure line stays.

```
<Primary keyword phrase as a full sentence: what the tool/agent does and the one number that matters.>
Free guide (commands, prompts, files): https://withhammad.com/resources/<slug>

<2-4 lines: steps or the catch, written for the reader who does not watch.>

Tested <date>: <what was verified>.
Sources: <repo / docs link>

Subscribe for the next AI build. AI-generated presenter; altered-content label on.
#Shorts #<TopicTag> #<ToolTag>
```

Title rule: <= 100 chars, key phrase in the first 50 (feed truncation, E7), `#Shorts` once, in the title OR the description, not both. Tags: 5-8, exact search phrases + misspellings, no generic default set. Related video: always set (Studio > Content > Short > Related video) to the weekly long video on the same topic, or to the closest long video (E4).

```
- Guide: https://withhammad.com/resources/<slug>
- Repo / docs: <url>

Watch next: <related long video url>
AI-generated presenter; altered-content label on.
#ClaudeCode #AIAgents #AIAutomation
```

End screen (video >= 25 s; last 5-20 s; up to 4 elements on 16:9, E5): 1 Subscribe, 1 "best for viewer" video, 1 playlist (the topic playlist), 1 Link only once in YPP (not available now, monetization off). Leave the last 15 s of the edit with a static lower third so elements do not cover text.

Thumbnail (E8): upload >= 1280x720 (YouTube now recommends 3840x2160), 16:9, JPG/PNG, <= 2 MB on mobile upload; run Test & compare with 3 variants, one variable at a time. Keep the glow-grid cover system from the Shorts so the channel grid reads as one brand.

Posting: time of day does not change 30-day views in a measurable way; YouTube states cadence is not a ranking input and recommends videos, not channels (E10, E11). Keep the fixed daily Shorts slots from analytics (docs/BEST_TIMES*.md) and publish the long video on the same weekday every week, with a Community post (image + poll) the same day; image posts can also surface in the Shorts feed (E12).
