## Page template (see the PNGs in this folder)
- Paper-texture light background on every page.
- Header bar: logo box left | guide title in a dark bar | arrow box right.
- Footer bar: "UNLOCK ALL AI TUTORIALS AT" + dark URL box + arrow, accent-colour stripe behind it.
- Cover: brand logo top, 2-line title (line 2 in accent colour), small sub-line, a big 3D hero object (product logo as a physical object), 1 sticker ("GUIDE"/"CERTIFICATE").
- Page 2: the promise ("All courses free, no paid subscription needed") + "The setup is inside: <url>" + "What you get:" + the product's own card.
- Item pages (one item per page): torn-paper number badge in accent colour + big 2-line title; 2 bullets (what it is; "Best for:"); a REAL screenshot of the item's page with a "Start the course here" callout pill; meta line (e.g. "14 lectures, 66 minutes of video").
- Upsell page: their guide library ("The Claude Bundle: from beginner to pro", Beginner/Intermediate/Advanced rows of e-book covers, "Free Download").
- Last page: "You've got the guide / Now put it to work" + "Don't wait for inspiration" + 3 accent bullets + stamped accent button "Unlock all our tutorials here / VISIT <URL>".

## Caption formula (every post)
Hook line + 🤖 → 2-3 one-line problem/promise lines (❌ / ✅) → "Here is …" → numbered emoji list (1️⃣ … 🔟, item + one line) →
"The bottom line:" / "Why this matters:" → "What you get now:" with → bullets → "Save this guide." → "♻️ Repost for someone who …" →
optional "Comment "Guide" for instant access" → "Content credit: <creator>" when adapted → "P.S. Unlock … Get it here ➡️ link".
