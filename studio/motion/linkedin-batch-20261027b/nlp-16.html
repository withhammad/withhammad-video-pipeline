THE NLP FIELD NOTEBOOK

Evaluating NLP

Measure the behavior you intend to ship

15.1

Classification

Precision asks how many predicted positives were correct; recall asks how many true positives were found. F1 balances both.

15.2

Generation metrics

BLEU and ROUGE measure forms of reference overlap. Semantic metrics add another signal, but neither replaces task-specific review.

15.3

Human review

Use a clear rubric for correctness, completeness and usefulness. Review disagreements instead of averaging them away.

15.4

Slices and baselines

Evaluate rare cases, languages and difficult inputs separately. Compare with a stable baseline and report sample size.

A score without a task is hard to interpret.
