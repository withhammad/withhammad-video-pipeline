Pretrained models

Match the model to the job

9.1

BERT-style encoders

Masked-language pretraining develops contextual representations. Add an appropriate head for classification or extraction.

9.2

GPT-style decoders

Causal pretraining learns next-token prediction. Instruction tuning can adapt that base capability to following requests.

9.3

T5-style models

Express many tasks as text-to-text transformations with an encoder-decoder architecture.

9.4

Selection checklist

Check license, language coverage, context length, hardware, latency and task evaluations. Parameter count alone does not decide quality.
