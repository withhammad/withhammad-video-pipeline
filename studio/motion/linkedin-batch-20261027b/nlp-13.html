THE NLP FIELD NOTEBOOK

Generating text

Decoding changes the output

12.1

Greedy decoding

Choose the highest-scoring next token each step. It is simple but can produce repetitive continuations.

12.2

Sampling

Draw from a probability distribution. Temperature rescales logits; top-k and top-p restrict the candidate pool.

12.3

Beam search

Track several candidate sequences. It can be useful for some constrained tasks, but is not a universal creativity setting.

12.4

Control and verify

Use stop conditions, length limits and schema validation. A low temperature does not guarantee truth or perfect reproducibility.
