17. Advanced patterns

Add complexity for a measured reason

17.1  Long context

•  More input capacity can help, but relevance, latency and retrieval quality still matter.

•  Test whether the extra context improves the task.

17.2  Multimodal systems

•  Text can be combined with image, audio or video representations.

•  Evaluate each input channel and their interactions.

17.3  Tool use and agents

•  A model proposes actions; an application executes permitted operations and feeds back results.

•  Keep stopping rules and budgets explicit.

17.4  Efficient inference

•  Caching, batching and quantization target different costs.

•  Benchmark quality and latency on the actual workload.

Add a component only when it earns its place.
