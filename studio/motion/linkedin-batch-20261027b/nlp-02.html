1. What NLP does

Language becomes a computational task

1.1  Start with an outcome

•  Route a support ticket, find an answer in a manual, extract a date, or summarize a conversation.

•  Each needs a different definition of success.

1.2  Understanding and generation

•  Classification assigns labels.

•  Extraction identifies spans.

•  Retrieval finds relevant documents.

•  Generation produces new text conditioned on input.

1.3  A practical baseline

•  Collect representative examples.

•  Reserve a test set.

•  Try simple rules or a small model before adding a larger system.

1.4  Where it gets hard

•  Ambiguity, domain jargon, sarcasm, multilingual input and changing data can all break an apparently strong demo.
