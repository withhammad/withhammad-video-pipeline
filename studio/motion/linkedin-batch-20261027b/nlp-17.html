THE NLP FIELD NOTEBOOK

Deployment and MLOps

Ship the whole system, then observe it

16.1

Version the pipeline

Track the model, tokenizer, prompt, retrieval index and evaluation set. A model version alone does not reproduce an application.

16.2

Serve predictably

Set timeouts, concurrency limits and response validation. Measure latency distributions, throughput and cost.

16.3

Monitor drift

Watch changing input patterns and real failure reports. Maintain a rollback path and refresh evaluation examples.

16.4

Protect access

Apply authentication, authorization and data boundaries in code. Model instructions are not a substitute for access controls.

Version → test → release → observe → improve
