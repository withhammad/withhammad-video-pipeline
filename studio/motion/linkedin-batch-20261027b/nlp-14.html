13. Retrieval and search

Find the evidence before drafting the answer

13.1  Lexical retrieval

•  BM25 rewards matching terms while accounting for term frequency and document length.

•  Exact identifiers often benefit from lexical search.

13.2  Dense retrieval

•  Embed a query and documents into a compatible vector space, then retrieve by vector similarity.

13.3  Hybrid search

•  Combine lexical and dense results.

•  A reranker can score a smaller candidate set with more expensive relevance judgments.

13.4  Measure retrieval

•  Use labeled queries and relevance judgments.

•  Recall@k and ranking metrics reveal failures an answer-only demo can hide.
