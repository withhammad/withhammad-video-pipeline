7. Attention

Select relevant information from context

7.1  Queries, keys, values

•  A query is compared with keys.

•  Normalized scores weight the values, producing a context-dependent mixture.

7.2  Scaled dot product

•  Compute QKᵀ, scale by √dₖ, apply any mask, then softmax.

•  Multiply those weights by V.

7.3  Self and cross attention

•  Self-attention reads from the same sequence.

•  Cross-attention uses queries from one sequence and keys and values from another.

7.4  Masks matter

•  Causal masks block future positions.

•  Padding masks exclude empty slots.

•  A diagram without the mask can teach the wrong dependency.

Attention(Q,K,V) = softmax(QKᵀ / √dₖ + mask)V
